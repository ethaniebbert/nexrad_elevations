NEXRAD lowest-beam height AGL

The lowest 0.5° beam height above ground and terrain blockage for every U.S. WSR-88D radar, computed against the Copernicus GLO-90 DEM.

  • nexrad_beam_height_agl.kml: for Google Earth Web (Projects → New project → Import KML file from computer)
  • nexrad_beam_height_agl.kmz: a single self-contained file for Google Earth Pro
  • radar_summary.csv: per-radar blockage statistics

Source code and method: github.com/ethaniebbert/nexrad_elevations
